# Segmentação de Programa de Fidelidade com SQL (CASE WHEN)

Este projeto simula uma necessidade comum nas áreas de CRM e Marketing de E-commerce: classificar a base de clientes em faixas de benefícios de forma dinâmica, sem precisar alterar a estrutura da tabela original.

# O Problema de Negócio
O sistema registra o valor total gasto por cada cliente, mas o time de marketing precisa visualizar rapidamente em qual nível do programa de fidelidade cada consumidor se enquadra para disparar campanhas personalizadas.

UTILIZEI: SQL, CASE WHEN, END AS, ORDER BY
